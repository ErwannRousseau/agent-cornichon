# Start and end pilot operations manually

The pilot lets colleagues decide to play two minutes before a meeting. The
organizer opens registration in Slack, and the operation starts manually once
the group is ready. Starting closes registration and sends each agent their
mission privately.

Scheduling and reminders ten minutes before a meeting can wait until the pilot
shows that colleagues want to play again.

When the meeting ends, the organizer or a registered agent can finish the
operation. This opens reporting and sends report requests by DM, so the requests
follow the actual end of the meeting.

Run the pilot in an agreed internal channel with volunteers during a recurring
team meeting. Keep client, HR, and sensitive meetings out of the pilot. The
first round checks the workflow. A colleague starting another round without a
prompt within seven days is the signal to revisit scheduling.
