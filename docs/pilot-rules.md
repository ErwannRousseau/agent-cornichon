# Pilot rules

## Slack workflow

- Open **Cornichon** from Slack’s `/` menu to see the private Pickle HQ menu
  with **Ouvrir les inscriptions** and **Mon score**.
- From a one-on-one DM, including a self-DM, the shortcut opens the menu in your
  DM with Agent Cornichon. The operation takes place there.
- A pinned **Ouvrir les inscriptions** button also lets players open
  registration from a channel.
- **Ouvrir les inscriptions** immediately posts the **Opération Cornichon**
  invitation with the player count and buttons to join, leave, and start.
- Agents receive missions and report requests by DM.

## Game rules

- An operation starts with 1 to 20 agents. The organizer or a registered agent
  can start it. The organizer joins the same way as everyone else. Agents can
  leave until the operation starts, when registration closes.
- A channel can host several operations in one day. An agent with an active
  mission in a channel cannot receive another mission there. That agent can play
  in a different channel, and other agents can play in the original channel.
  Finishing or canceling the operation frees the agent to play again, even with
  a report pending. The app checks eligibility during Slack interactions.
- The app checks eligibility when an agent joins and again when the operation
  starts. It privately explains why registration was blocked if the agent
  already has a mission in that channel. At launch, only eligible agents receive
  words. At least one eligible agent is required.
- The organizer or any registered agent can finish an active operation.
- The organizer can cancel during registration or play. Canceling closes the
  operation without requesting reports or awarding pickles.
- At launch, each agent gets one random word from a list of 150. A word is
  assigned only once per operation.
- Agents receive their mission and report request in DMs, where they can submit
  the result.
- Agents report their own results. Saying the word during the meeting counts as
  a success even if someone notices. The first submitted result is final.
- Each report request belongs to a specific mission. Agents can report late,
  even after playing another operation. An unsubmitted report earns zero
  pickles.
- Each success earns 30 pickles. The list mixes words that fit easily into a
  meeting with words that lend themselves to an absurd comparison.
- Results and scores are private. Public leaderboards and operation summaries
  are deferred.

## Game data

Agents can ask the pilot lead to delete their game data. The lead explains that
existing DMs follow the workspace’s Slack retention settings.

## Pilot test

Start with a recurring meeting in an agreed internal Slack channel with a
volunteer team. Each colleague chooses whether to join. The pilot excludes
client, HR, and sensitive meetings.

The first round checks the full workflow. Before considering scheduling, look
for a colleague to start another operation on their own within seven days.
